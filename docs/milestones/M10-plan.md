## 需要业主决定的问题(我的推荐在前)

1. **sidecar 打包**:推荐「node 二进制 + esbuild 单文件 + 原生模块作为资源」,第一个 PR 实测体积后再定,超过 80 MB 改 SEA。
2. **桌面登录方式**:推荐「一次性启动令牌换会话 Cookie」(仅回环、60 秒、用后即失效)。这是新的认证入口,需要你批准;替代方案是壳把个人访问令牌注入 Web 的请求层,但要给 Web 写第二套请求代码。
3. **API Key 存钥匙串**:推荐本里程碑不做(会新增 `keychain:` 引用形式,属于密钥格式变更),先用加密 `secrets.yaml`,以后单独写 ADR。
4. **桌面数据目录**:推荐用应用自己的数据目录,与命令行 / Docker 的 `~/.fatcat-ai` 分开;「导入已有数据」放设置里并先备份。涉及真实数据,实现前会再请你确认。
5. **updater 密钥**:推荐由你生成密钥对,私钥放仓库 Actions secret,公钥我写进配置。

## 仅业主可做

生成 updater 密钥并配置 secret;三平台真机验证(托盘、快捷键、开机自启、深链接、冷启动时间、安装说明、真实 GPU 帧率);确认未签名安装包的安装步骤。
