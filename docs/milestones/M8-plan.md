## 需要业主决定的问题(我的推荐在前)

1. **同意迁移 0019 吗?**(新表 `agents` + `runs` 两列,迁移前自动备份,旧版本打不开新库)——推荐同意;不同意就无法做 M8,可以把 M8 整体推迟。
2. **子代理默认不带 `delegate`**(只有显式加入才能再委派,且受 `max_depth=2` 限制)——推荐这样,更安全;代价是复杂调研需要多配置一步。
3. **并行度默认 3、整棵树共享预算**——推荐;预算数值(token / 秒)的默认值我会在第 2 步的 PR 里给出并写明依据,不拍脑袋。
4. **预置角色的工具集**按 ADR 第 5 节;邮件秘书不含发送(发送仍需审批)——推荐。
5. **恢复语义**:只从最后一个已完成的工具结果继续,不重放有副作用的工具——推荐。

用户不回复就按推荐做,**但迁移(第 1 条)必须等业主明确同意**,在此之前不写任何代码。
