## 二、与方案的偏差

1. **「恢复」没有做**:子运行与委派者在同一个进程里同步等待,重启后整棵树都失败,用户重试。做成续跑需要持久化每个步骤的模型上下文,先按推荐不做(PR 描述里已向业主提问)。
2. **取消只能取消整棵树**:取消任何一个节点都转到根运行。单独取消子节点会让委派者拿到半截结果。
3. **`own` 记忆分区没有做**,创建时被拒绝(ADR 0042 第 4 节),界面里也不提供。
4. **并行上限按每个运行**(默认 3),不是整棵树;整棵树最多 3^深度 个,避免父子互相占满名额而死锁。
5. **不返回用量的模型提供方只受时间预算限制**(用量按 0 计)。
6. 任务还不能指定代理,所以定时任务里不会出现委派;任务页「等待批准」已按整棵树统计。
