# ADR 0039 · 预授权域名范围:匹配规则、输入校验与任务工具集评估

状态:已采纳(随 PR「fix(tasks): 预授权域名体验」)。背景:M6 真机测试里用户在预授权里填了 `bbc.com`,模型实际请求 `www.bbc.com`,精确匹配不生效,界面上没有任何说明。

## 1. 匹配规则(用测试固定)

实现在 `packages/shared/src/domain-scope.ts` 的 `matchesDomain`,Web 提示、服务器校验和工具策略共用同一份:

| 写法            | 匹配                               | 不匹配                                    |
| --------------- | ---------------------------------- | ----------------------------------------- |
| `example.com`   | `example.com`                      | `www.example.com`、任何子域               |
| `*.example.com` | 所有子域,含多级(`a.b.example.com`) | **`example.com` 本身**、`evilexample.com` |

**决定:`*.example.com` 不匹配 `example.com` 本身。** 理由:通配符写法的含义是「某个站点下的所有子域」,把根域一并放行属于扩大授权,而用户要放行根域时可以明确再写一条。两个写法可以同时填(逗号 / 空格分隔),界面在用户只填裸域名时提示一键补上 `www.` 或 `*.` 的写法。主机名比较不区分大小写,忽略末尾的点。

## 2. 输入校验

`parseDomainScope` 规范化(小写、去空白与末尾的点)并给出稳定的原因:`protocol`(带 `http://`)、`path`(带 `/ ? #`)、`port`(带 `:`)、`broad`(`*.com` 这类只有一段的通配,等于放行整个顶级域)、`invalid`、`empty`。

- Web:输入时即时显示中文报错,有问题时不能保存。
- 服务器:任务白名单里的 `*.com` 返回 400 `task_domain_broad`;带协议 / 路径 / 端口的写法本来就过不了 `PreauthConstraint` 的 schema(小写主机名正则),同样返回 400。聊天里「记住这个决定」走 `web.fetch` 的 `normalizeConstraint.domain`,用同一个解析函数。契约不变(只在校验上更严,没有新增字段)。
- 不支持 IDN 原文(中文域名):请填 punycode,与 `fetchHost` 取到的 `URL.hostname` 一致。

## 3. 库里已存下的无约束条目

`web.fetch` 等声明了 `requireConstraint` 的工具,保存时必须带约束。但更早版本留下的永久 / 会话预授权可能没有约束,等于放行所有网站。`decideCall` 现在对库里取出的条目和任务白名单都过滤:工具要求约束而条目没有时,不参与匹配(条目保留不删,用户仍能在设置里看到并撤销)。

## 4. 评估:任务确认卡声明所需工具集合

问题:无人值守任务的提示里写了「只用相关工具」,模型仍偶尔调用 `kb.search`、`items.*`。

方案:`TaskPolicy` 增加可选 `toolSet`(工具名或前缀的数组;缺省 = 现状),确认卡上由用户确认,运行时 `runner` 只把集合内的工具交给模型,集合外的硬调用按未知工具处理(已有 `withholdToolPrefixes` 的做法,实现约 20 行)。

结论:**可行,建议做,但单独开 PR,不在本 PR。**

- 它只会缩小模型能用的工具,不会放大授权(审批与预授权仍照常判定),所以安全上是收紧方向。
- 需要新增契约字段(只增)、确认卡上的勾选界面、自然语言建任务时让模型给出建议集合(模型给的集合只是建议,由用户在卡上确认),以及一条越权用例:集合外的工具被硬调用时不执行。
- 风险是漏勾:任务需要的工具不在集合里时会失败,所以默认不设集合(全部工具减去 `withholdToolPrefixes`),确认卡上建议集合并让用户可见;运行记录里对「未知工具」的失败要给出明确文字。
- 这是一个小而完整的功能,不涉及数据库迁移(`policy` 存在任务的 JSON 里)。

## 5. 遗留

DSML 测试数据尚待用户提供真机抓到的数据流后替换,本 PR 不改。
