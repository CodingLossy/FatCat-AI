# ADR 0044 · 桌面应用(M10)

- 状态:提议(M10 方案,待业主审阅;未开始写代码)
- 日期:2026-11-18
- 相关:开发计划 M10 一节、4.1.1 知识地图;ADR 0001(技术栈)、ADR 0003(条目索引)、ADR 0004(API 约定)、ADR 0026(密钥加密)、ADR 0030(API v1 冻结)、ADR 0043(i18n)、`docs/milestones/M10-plan.md`

## 背景

开发计划把桌面应用定为「API v1 的一个客户端 + 可选内嵌核心」:Tauri v2 壳加载 `apps/web` 的构建产物,核心服务器作为 sidecar 随壳启动。现状:

- 服务器是 `tsc` 编译出的 ESM(`apps/server/dist/index.js`)加 `node_modules` 里的工作区依赖,运行在 Node 24;其中 `better-sqlite3` 是原生模块。**没有**单文件产物。
- Web UI 是 Vite 构建的静态文件,服务器用 `FATCAT_AI_WEB_DIR` 托管;认证是 Cookie 会话 + CSRF,也支持个人访问令牌(`Authorization: Bearer`)。
- `packages/ui` 里已有 `VoiceOrb`(Three.js 之外的纯逻辑 + 渲染)与 `CategoryBrowser` 的逻辑层。
- `apps/desktop` 只有占位 README。云容器里没有图形界面,**桌面壳在这里只能编译、不能点**。

## 决定

### 1. 壳与核心的关系

壳只做进程守护、端口协商、窗口与原生能力;所有业务都经 `/api/v1`。壳启动 sidecar 时:

- 监听 `127.0.0.1` 的**随机端口**(不用固定的 8787,避免和开发中的服务器冲突),数据目录默认 `app_data_dir`(与命令行 / Docker 的 `~/.fatcat-ai` 分开,避免两个核心写同一个库;「使用已有数据目录」放设置里并提示备份)。
- 窗口加载 `http://127.0.0.1:<端口>/`,即让服务器托管 Web 构建产物(与现在 Docker 里一样)。这样 Cookie / CSRF / SSE / WebSocket 的行为与浏览器完全一致,Web UI 不需要为桌面写第二套请求层。
- **登录**:壳生成一次性的随机启动令牌,经环境变量交给 sidecar;sidecar 只对 `127.0.0.1` 提供 `POST /api/v1/auth/desktop-session`(带启动令牌、用后即失效、有效期 60 秒),成功后给出主人账户的会话 Cookie。没有主人账户时走正常的首次设置流程。这是**安全相关的新入口**,需要业主批准(见问题 2),并带越权用例:错误令牌、重放、非回环来源、过期都必须被拒。
- 壳退出(含崩溃)时 sidecar 必须退出:壳持有子进程句柄并在退出钩子里终止;sidecar 自己监视父进程管道,管道关闭就退出(防止残留进程,验收项)。

### 2. sidecar 怎么打包(先量再定)

计划写的是「Node SEA 产物;备选:附带 node 二进制 + bundle.mjs」。`better-sqlite3` 是原生模块,SEA 不能直接内嵌 `.node` 文件,所以**推荐备选方案**:

- 用 esbuild(MIT,已在依赖树里)把 `apps/server` 及工作区包打成一个 `server.mjs`,`better-sqlite3` 的预编译 `.node` 与官方 `node` 二进制作为 Tauri 资源一起放进安装包。
- 体积是验收项(三平台安装包 ≤ 80 MB)。Node 24 二进制压缩后约 30 MB(未实测),加上 Tauri 壳、Web 产物和原生模块,预计在 50–65 MB,**但这是估计,第一个 PR 先做可行性验证并把实测数字写进 ADR,超过预算就改 SEA 或裁剪**。
- 冷启动 < 3 s 也在第一个 PR 里量(sidecar 启动到 `/healthz` 返回)。

### 3. 原生能力

系统托盘(关窗驻留)、全局快捷键唤起「快速提问」小窗、开机自启、系统通知、文件拖拽(只传路径给对话,文件工具仍受授权目录限制)、深链接 `fatcat-ai://`、「本地模式 ⇄ 连接远程服务器」切换(远程模式不启动 sidecar,窗口指向用户填的 HTTPS 地址,登录走普通登录页)。使用 Tauri 官方插件(MIT / Apache-2.0)。

深链接只接受一组白名单动作(打开会话、快速提问并预填文本),**预填文本不自动发送**,避免网页或别的程序通过链接让助手执行操作。

### 4. API Key 存系统钥匙串(需业主决定)

计划列了「API Key 存系统钥匙串」。现在密钥引用只有 `env:` 和 `file:` 两种(ADR 0026,M1 决定「密钥只以引用出现」)。接入钥匙串意味着新增 `keychain:NAME` 引用形式,是**密钥格式变更**,按约定必须业主先决定。推荐:本里程碑**不做**,先用已有的加密 `secrets.yaml`(桌面首次启动自动生成主密钥并存在应用数据目录的受限文件里,与 Docker 方案一致);钥匙串作为后续单独的 ADR。

### 5. 知识地图粒子球 `KnowledgeSphere`

放在 `packages/ui`,复用 VoiceOrb 的 Three.js 渲染层(Three.js 是 MIT,但要确认 `check:licenses` 通过),只用 `/api/v1/items/*`:

- 顶层类别簇 → 点击展开子类别 → 递归到内容条目(打开 / 问 AI);面包屑、返回、键盘导航、与树形视图一键切换;`subtree?depth=2` 预取。
- 无 WebGL 或「减少动态效果」时自动用树形视图(`CategoryBrowser`),不是报错。
- 性能验收(切层 ≤ 600 ms,1 万条目 60 fps)用一个合成数据集 + Playwright 的 headless 渲染量帧时间;**真实 GPU 上的 60 fps 只能在业主的机器上确认**。
- Web UI 同步获得该组件(桌面优先打磨)。逻辑层(布局、下钻状态、键盘导航)是纯函数并带单测。

### 6. 记忆与会话可视化

按《记忆模块补充设计》第 7、9 节:记忆簇按类型着色、亮度表示置信度与分层、冲突描边;会话地图 2D 画布(fork 关系、点击定位到消息、与知识地图互跳)。数据来自现有 `/memory` 与 `/sessions` API,不新增端点;如果缺字段(比如 fork 关系)先写 ADR 再增量加。

### 7. 安装包、更新与发布

- 三平台安装包(Windows MSI / NSIS、macOS dmg、Linux AppImage / deb / rpm)在 CI 的三个系统 runner 上构建。**不买付费代码签名**:macOS ad-hoc 签名、Windows 不签,安装说明写「右键 → 打开」/ `xattr -dr com.apple.quarantine` / SmartScreen「仍要运行」(进文档站)。
- 发布页提供 SHA-256 校验和与 cosign 签名。
- Tauri updater 的更新签名需要一对密钥:**私钥只能由业主生成并放进仓库的 Actions secret,C 不接触也不写进任何文件**;公钥写进配置。更新源是 GitHub Releases;用户可在设置里关闭更新检查(与「无遥测」一致,检查只访问 GitHub Releases)。
- Rust 依赖也要过许可证白名单:CI 加 `cargo deny`(与 `check:licenses` 同一份白名单),并检查没有遥测 crate。

### 8. 不做的事

不做付费签名与公证;不做移动端(M11);不做自带的自动登录以外的账号体系;不在壳里加遥测或崩溃上报;不把核心嵌进壳的进程(保持 sidecar,崩溃互不影响)。

## 验收对照(开发计划 M10)

| 验收项                                                     | 怎么验                                                         |
| ---------------------------------------------------------- | -------------------------------------------------------------- |
| 三平台安装包 ≤ 80 MB                                       | CI 的构建产物体积检查;超限即失败                               |
| 冷启动到可对话 < 3 s                                       | sidecar 就绪时间在 CI 里量(Linux),Windows / macOS 由业主实测   |
| 关窗驻留托盘,sidecar 随壳退出无残留进程                    | 自动化测试覆盖「壳崩溃后 sidecar 退出」;三平台托盘行为业主实测 |
| 粒子球 ≥ 4 层下钻并「问 AI」,切层 ≤ 600 ms,1 万条目 60 fps | 合成数据集 + headless 量帧;真实 GPU 业主实测                   |
| 无 WebGL / 减少动态效果自动用树形视图                      | 单测 + Playwright(关闭 WebGL)                                  |
| 未签名安装包的安装说明经三平台实测                         | 业主在三个系统上实测后确认                                     |
