---
title: 家庭成员账户
description: 管理员用邀请码添加成员、重置密码、停用与删除账户。
---

FatCat-AI 2.0 起,一个服务器可以有多个账户。第一个账户是**管理员**,之后的账户由管理员邀请,默认是**成员**。每个账户的会话、记忆、邮件、任务、渠道和设备都是自己的,别人看不到;管理员只管账户本身,也看不到成员的数据。

> 多用户还在开发中(ADR 0053 共 6 个 PR)。成员自己的模型密钥和共享模型配置档、把插件开放给成员在后面的 PR 里。

## 添加成员

1. 管理员打开 **设置 → 系统设置 → 账户与设备**,在「账户」一节点 **生成邀请码**。
2. 邀请码只显示这一次,24 小时内有效、只能用一次。把它交给对方(当面或私聊)。
3. 对方打开登录页,点 **有邀请码**,输入邀请码,自己设用户名和密码,创建后直接登录。

用户名已被占用时邀请码不会作废,换个用户名再试即可。同一时间最多有 10 个未用的码。生成邀请码的管理员被停用或降为成员后,他生成的码都不能再用。

## 忘记密码

管理员在成员那一行点 **生成重置码**,把码交给对方;对方在登录页点 **有重置码**,输入码和新密码。重设之后,这个账户在所有地方的登录、个人访问令牌和配对的设备都会失效,要重新登录。管理员不能给自己生成重置码,忘了密码时请另一位管理员生成。

唯一的管理员忘了密码时,在服务器本机改:

- 从源码运行:在仓库的 `apps/server` 目录(先 `pnpm build`)执行 `node dist/index.js auth reset-password <用户名>`,按提示输入两次新密码(输入时不显示)。
- Docker:在仓库的 `docker/` 目录执行 `printf '%s\n' '新密码' | docker compose -f docker-compose.prod.yml exec -T fatcat-ai node dist/index.js auth reset-password <用户名>`(密码从标准输入读,不出现在命令参数里;用 `printf` 时它会留在 shell 历史里,用完可以清掉)。

新密码至少 12 个字符。改完后这个账户的登录、令牌和设备全部失效,两步验证保留,并写一条审计。服务器开着或停着都可以运行。

## 角色、停用与删除

- **设为管理员 / 改为成员**:管理员可以改别人的角色,不能改自己的;至少要留一个未停用的管理员。
- **停用**:这个账户立即退出所有登录(浏览器、令牌、设备,已连上的也会断开),它的定时任务、渠道、邮件同步和 MCP 服务器都停下。停用的账户登录时得到的回答和密码错误一样。**启用** 后恢复后台工作,但要重新登录。
- **删除**:要输入对方的用户名确认。删除前自动备份数据库到数据目录的 `backups/`(文件名形如 `db-…-pre-delete-account.sqlite`),然后删掉这个账户的全部数据,以及 `secrets.yaml` 里这个账户的密钥行(其他行不动)。不能删除自己。

账户管理只能在浏览器里登录后操作:个人访问令牌和手机设备令牌都不行;开了两步验证的管理员要先通过验证码。

## 只有管理员能开的能力

服务器以一个系统用户运行,下面这些能力等于让助手在这台机器上做事,所以只有管理员能配置:

- **授权文件夹**:只有管理员能添加和撤销。管理员在「账户」里成员那一行点 **分配文件夹**,把某个文件夹分给这个成员;成员在「设置 → 工作台 → 文件夹」只看到分给自己的,可以选是否加入知识库,不能自己添加或撤销,写入仍然每次审批。同一个文件夹可以分给几个人。
- **MCP 服务器**:只有管理员能添加和启用;成员的设置页只显示一句说明。
- **插件**:只有管理员能安装、升级、回退、启用和改设置。把插件开放给成员在后面的 PR 里。
- **编码项目**(`git.*`、`code.run`):只有管理员能配置和使用。
- **嵌入模型**:整个服务器共用一个(换模型要重建全部向量),只有管理员能建 embed 用途的模型配置档和重建向量;成员的知识库也用它。
- **密钥文件**:状态和加密迁移只有管理员能看、能做;每个账户自己的密钥见下一节。

管理员被改为成员后,他原来配置的 MCP 服务器、插件和编码工具立即停用(配置保留),再设回管理员就恢复。

## 密钥与共享模型

每个账户都可以在「设置 → 系统设置 → 密钥 → 我的密钥」里保存自己的 API Key、邮箱授权码等:填键名和值,保存后只显示名字和要填的引用(例如 `file:OPENAI_API_KEY`),值不会再显示。在模型配置档的「密钥引用」或邮箱的密码里填这个 `file:` 引用就行。

- 成员保存的密钥只有他自己的配置档和邮箱能用,其他账户(包括管理员)看不到也引用不了。成员的引用里会出现一串账户编号(`file:U…_OPENAI_API_KEY`),这是正常的,原样填就行;填不带编号的 `file:OPENAI_API_KEY` 也会自动换成自己的。
- `env:` 引用读的是服务器的环境变量,只有管理员能用。
- 删除一个密钥后,用到它的配置档和邮箱会显示「缺失」。删除账户时,它保存的密钥一起删掉。

管理员可以在模型配置档里勾选 **共享给成员**,让全家用同一个模型账号。成员在模型列表里看到这一项标着「管理员共享」,可以在对话、默认模型和语音里选它,但看不到接口地址和密钥引用,也不能修改、删除或测试连接。管理员取消共享、被改为成员或被停用后,成员就不能再用它。

## 登录限速

同一个来源地址连续输错密码 5 次,或同一个用户名(无论从哪里)连续输错 5 次,都会被暂时锁住,要等一会儿再试。邀请码和重置码的输入也有同样的限速。
