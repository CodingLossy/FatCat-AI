---
title: 接入微信
description: 把助手接到微信:扫码登录、配对、在微信里批准操作。
---

1.0 只含微信渠道;企业微信推迟、排期另定,QQ 以后再说。每个渠道只接受一个主人账号。

## 步骤

1. **登录**:「设置 → 渠道」添加一个微信渠道并启用,点「扫码登录」,用要当作助手的微信账号扫码,并在手机上确认。
2. **配对**:点「生成配对码」,用**你自己的**微信私聊助手账号,发送「绑定 123456」(换成页面上的配对码)。之后只有你的私聊消息会进入对话;其他人的消息和群消息一律忽略,不回复,也不会发给模型。
3. **在微信里批准操作**:需要批准的操作会发到微信,回复「确认 K7」或「拒绝 K7」(K7 换成消息里的编号)。
4. **登录失效**:渠道显示「需要扫码登录」时重新扫码即可。

## 微信里的命令

| 发送                | 作用                                                                                |
| ------------------- | ----------------------------------------------------------------------------------- |
| `/clear` 或「清空」 | 只清空这个渠道的当前会话,记忆不会删除                                               |
| `/map`              | 浏览知识地图:回复编号下钻,`0` 返回,「下一页」翻页;只显示标题与摘要,正文请在网页打开 |

在网页的会话列表里,可以删除单条对话,或「清空全部对话」(同样保留记忆)。

## 登录令牌存在哪里

登录令牌保存在数据目录的 `secrets.yaml`(键名 `ILINK_TOKEN_<渠道 id>`)。服务器写入前会把原文件复制到 `backups/secrets-<UTC 时间>.yaml`(密钥文件已加密时是 `.yaml.enc`,密文原样备份;权限 600,只保留最近 5 份),只改这一行;`secrets.yaml` 解析失败时不写入。在 Windows 上写完后会去掉继承来的访问项,只给当前用户完全控制。删除渠道时同样只删这一行。

## 目前的限制

暂不支持图片、文件,以及需要输入 PIN 的登录。
